# YOUPI PG — Visual-only Render preview

This package contains original HTML layouts extracted from the uploaded YOUPI PG source. All script tags have been removed; this is **not** a functional gateway or security-test environment.

## Deploy to Render
1. Upload the **contents** of this ZIP to the root of your GitHub repository.
2. In Render choose New > Static Site, connect the repository.
3. Build command: `echo ready`
4. Publish directory: `.`
5. Deploy.

No bank accounts, API keys, or databases are required.
